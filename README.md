# WanderWise Guide

Build a web application that helps women travel alone with confidence. The user enters a destination city, a place they want to visit, and optionally the time of visit. The app uses AI to generate a "Travel Confidence Guide" that includes safety considerations, best visiting times, transportation logistics, and practical tips for solo female travelers. The interface should include an input form and a results dashboard.
